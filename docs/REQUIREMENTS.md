## 1. 约定与范围

- 产品决策来自本次需求讨论。标为「执行默认值」的细节是为了让开发任务可执行而补充的默认规则，可以调整，不代表用户逐项确认。
- 保持 Swift 6、SwiftUI + AppKit、macOS 14 起、本地优先、无账号或后端。默认不启用 App Sandbox，不添加非必要依赖。
- 不要求一个版本交付所有功能。每个阶段必须可运行、可验收，不能用占位按钮冒充已实现功能。
- 本轮文档范围：快捷键配置、应用启动与切换、截图选择与编辑、标注、输出、置顶、最近截图、拼图、滚动截图、模块生命周期、鼠标手势、剪贴板历史和应用分组窗口切换。
- Todo、云同步、发布签名和自动更新不属于本轮代码范围。

## 2. 全局快捷键

### HK-01 动作与配置入口

设置增加「快捷键」页，分为「nylai 功能」「应用」。

- 支持内部功能动作和其他应用的启动／切换。
- 内部动作由程序提供，用户不能删除动作，但可修改、清除、启停其快捷键。
- 应用绑定可添加、修改、删除；同一个应用只允许一条绑定、一组快捷键。
- 提供总开关和每条绑定开关。停用保留配置，释放实际快捷键占用。
- 当前动作与默认值：打开设置不分配快捷键；截图 `⌥A`。快捷键模块默认开启。
- 后续「最近截图」「拼图」等动作在功能真正完成后才加入动作目录。执行默认值：新动作初始不绑定，不擅自改动现有键位。

### HK-02 按键录入

- 支持修饰键 + 一个按键；至少包含 Command、Option、Control 之一，可叠加 Shift。
- 不支持连续按键、双击修饰键、鼠标手势、单独修饰键或仅 Shift + 按键。
- 点击录入控件后进入录入态，收到合法组合后结束录入并尝试应用；录入态必须有清晰的视觉反馈。
- 执行默认值：不带修饰键的 Esc 取消，Backspace / Delete 清除绑定；仅按修饰键继续等待；非法组合显示原因，保留原配置。
- Fn / 地球仪不作为可配置修饰键。F 键仅在系统发送标准 F 键事件时按普通按键处理，不申请输入监控权限读取媒体键。
- 录入期间不能触发 nylai 的截图、应用切换等动作；退出录入、关闭设置或失去录入焦点后必须恢复正常处理。
- 持久化物理键码与标准化修饰键，不保存显示字符串作为匹配依据；显示名称按当前键盘布局生成。切换输入源不能改变保存的物理键位。

### HK-03 生效、冲突与恢复

- 合法修改立即生效并自动保存，无额外「保存设置」按钮。
- 应用内重复绑定必须拦截。执行默认值：停用项中保留的非空绑定也参与重复检查，避免重新启用时才发现同应用配置冲突。
- 系统／其他应用占用按系统注册结果反馈；不能宣称检测到了所有第三方键盘监听冲突。
- 新键注册失败、配置写入失败时，原配置不能被新值覆盖；原键能够恢复注册时继续生效。
- 总开关关闭、条目停用或清空时不保留系统注册。此时可保存合法组合，但标记为未启用，外部占用在真正启用时验证。
- 启用总开关时逐条恢复：失败条目标出原因，不影响其他成功条目；不能把整个配置清空或静默换键。
- 必须区分未绑定、条目停用、总开关停用、已注册、注册失败；重试只针对失败项。
- 录入期间若临时释放注册，必须在所有退出路径恢复；恢复失败保留配置并显示实际错误，不能虚报「已启用」。
- 窗口切换模块独立管理系统切换键；HK 录入器仍拒绝普通动作绑定 Command+Tab，不把专用切换会话当作普通一次性动作。
- 执行默认值：首批明确拦截 Command+Tab、Command+Space、Control+Space、Command+Option+Esc、Control+Command+Q，以及 Command+Q/W/H/M/逗号；用准确组合表实现，不声称覆盖系统所有保留键。
- 配置损坏或版本不支持时保留原文件并显示错误，不静默重置。首次安装写默认值；用户主动清空后重启不能重新填入默认键。

### HK-04 应用启动与切换

| 目标状态 | 触发结果 |
|---|---|
| 未运行 | 启动并激活 |
| 已运行，在后台／隐藏 | 激活并显示其窗口 |
| 在前台，已开启「再次触发隐藏」 | 隐藏，交由 macOS 恢复之前的前台应用 |
| 在前台，未开启该选项 | 保持前台 |

- 「再次触发隐藏」每条应用绑定独立配置，默认开启。
- 隐藏不等于最小化，不退出应用；不为了实现返回切换而申请辅助功能权限。
- 执行默认值：使用系统文件选择器添加 `.app`，记录 bundle ID 与选取位置；不递归扫描用户磁盘。相同 bundle ID 视为同一应用。
- 优先定位用户所选应用；应用移动后可按 bundle ID 重新定位；找不到时保留绑定，提示重新选择。
- 应用更换位置但身份不变时不丢失键位。无有效 bundle ID 的包明确拒绝，不猜测身份。
- 不新增空白窗口、不指定某个窗口；沿用 macOS 的应用激活行为。目标应用本身不提供窗口时，不虚构窗口。
- 同一应用启动尚未完成时，重复触发不并行启动。失败后可以再次触发。
- 执行默认值：一次按下最多触发一次；长按不反复启动、隐藏或激活，松开后再次按下才重新触发。

## 3. 截图交互与来源

### CAP-01 入口与屏幕边界

- 提供单一「截图」动作：在鼠标所在显示器冻结画面，支持自由框选、整屏选择和自动识别窗口，不并列独立的主显示器动作。窗口与整屏属于同一组目标，窗口优先命中，当前显示器作为空白区域的目标。
- 首版编辑与区域选择限定在一个显示器，不支持跨显示器拖出同一个区域。
- 执行默认值：整屏截图后也进入编辑，初始选区为整幅图；后续不再直接打开保存面板。
- 截图不包含鼠标和 nylai 的选择遮罩、工具栏、设置窗口及置顶窗口。
- 系统授权仅在实际需要捕获时请求；拒绝／撤销时给出恢复入口，不输出伪截图。

### CAP-02 自由选区与调整

1. 触发后显示冻结画面和选取提示，不立即保存。
2. 鼠标所在位置自动命中窗口；没有窗口时命中当前显示器，不提供独立的全屏按钮或全选快捷键。
3. 拖动创建矩形选区，松开后显示边框、八个居中于边线的调整手柄、左上角像素尺寸与两类工具栏。
4. 可以移动选区、拖边或角调整尺寸，再绘制标注。
5. 标注坐标属于原图，不跟随选区移动或缩放；超出选区部分仅隐藏，扩大选区后可恢复。
6. 选区不能超出原图；执行默认值：最小为 1×1 原图像素，零面积拖动不进入编辑。
7. 底部放标注工具和阴影；右侧放选区、选择标注、撤销／重做／删除、滚动截图和输出操作。两组工具优先放选区外，全屏或贴边时收进选区内部，不跑出屏幕且不得相互遮挡。
8. 选区确认后，普通区域和功能控件使用箭头光标；只有绘图落点使用十字光标。工具栏使用统一图标，悬浮显示动作提示。

执行默认值：只有「选区」工具负责拖动选区；「选择」工具负责标注对象；绘图工具下拖动创建标注，避免同一手势含义不明确。

### CAP-03 自动识别与真正的窗口截图

- 鼠标悬停自动高亮候选应用窗口，点击选定后进入编辑；支持切换到自由框选。
- **输出只包含目标窗口本身，不包含遮挡它的其他窗口。不能用屏幕矩形裁切冒充窗口截图。**
- 第一批识别应用窗口，不识别内部控件或面板；截图时应包含触发前已显示的本应用窗口，同时排除桌面、菜单和系统浮层。
- 候选按窗口前后关系命中，不能只凭数组顺序猜测；遮挡与重叠场景必须人工验证。
- 原生窗口截图需先验证 ScreenCaptureKit 的独立窗口捕获。冻结的是选择界面的画面，不是暂停其他应用；目标窗口在选定时独立捕获。
- 执行默认值：包含窗口标题栏，不包含系统窗口阴影；用户需要阴影时通过统一外观设置添加。
- 执行默认值：窗口源图只允许在其原始范围内裁切，向外不能补出不存在的桌面内容。需要窗口周边桌面时切换自由选区模式。
- 执行默认值：第一批跨屏窗口不列为可选目标，避免与单显示器边界冲突；后续另行扩展。
- 窗口消失、最小化或捕获失败时保留可恢复的选择流程，不能静默截错窗口。

### CAP-04 编辑状态与取消

- 每次只允许一个活动截图编辑会话；再次触发截图时回到现有会话，不启动第二个覆盖层。
- 编辑态内不触发 nylai 的应用切换绑定，避免把绘图操作变成应用切换。
- Esc 优先取消当前拖动／未提交的标注；没有正在执行的操作时取消整个截图，不落盘、不记录历史。
- 执行默认值：主动切换到其他应用时取消未输出的截图；本应用的保存面板、颜色面板不算切出。
- 保存面板取消或输出失败，返回同一编辑会话，保留选区和标注；成功复制、保存后关闭编辑；置顶成功后转为悬浮图片。

## 4. 标注与外观

### EDIT-01 第一批工具

| 工具 | 行为 |
|---|---|
| 矩形、椭圆 | 描边标注；可修改边界和样式 |
| 直线、箭头 | 拖动两端确定位置；支持之后调整端点 |
| 自由画笔 | 按鼠标轨迹绘制，可整体移动和缩放 |
| 文字 | 文字、颜色、字号；支持多行 |
| 步骤编号 | 顺序编号的圆形标记，可移动和调整大小 |
| 矩形打码 | 像素马赛克，可调整区域与块大小 |

记号笔、毛笔笔触列为后续批次，不用普通透明线冒充已实现毛笔效果。

### EDIT-02 样式与对象编辑

- 线条支持颜色、粗细、实线／虚线；文字支持颜色和字号；每种工具分别记住最后使用的样式。
- 已绘制对象支持选择、移动、调整大小、修改样式、删除；支持撤销／重做。
- 选中对象时修改其样式；没有选中对象时修改该工具的新建默认样式。
- 执行默认值：矩形和椭圆初期不提供填充；文本使用系统字体，不提供字体库。
- 执行默认值：文字框拖动调整时等比调整字号；自由画笔缩放轨迹但不自动改变线宽。线和箭头以端点编辑。
- 执行默认值：步骤从 1 开始，新增取当前最大编号 +1；删除不重排其他编号；撤销能恢复原编号。
- 执行默认值：一次拖动、一次样式调整、一次文字提交各算一次撤销；修改选区也可撤销。撤销后新操作清空重做分支。
- 正在输入文字时 Enter 换行、Command+Enter 提交；Esc 撤销未提交文本；空文本不生成对象。

#### 首批样式执行默认值

以下为实现起点，不是新增功能承诺。参数集中定义，不能散落在不同渲染器中。

| 参数 | 默认／范围 |
|---|---|
| 描边颜色 | 红色 `#FF3B30`；弹层左侧提供常用色阶，右侧提供饱和度／亮度、色相和 HEX 任意颜色输入，不调用系统取色器 |
| 描边粗细 | 3 px；1–24 px |
| 线型 | 实线；虚线的实段为线宽 3 倍、间隔为线宽 2 倍 |
| 字号 | 18 px；8–96 px |
| 步骤圆直径 | 24 px；16–96 px |
| 马赛克块边长 | 12 px；4–40 px |
| 圆角 | 关闭，开启时 12 px；限制在 0 至输出短边一半 |
| 阴影 | 关闭；开启时黑色、25% 透明度、12 px 模糊、向下偏移 4 px；透明度 0%–100%，模糊与偏移 0–64 px |

### EDIT-03 打码与导出

- 马赛克为真实像素处理，不能只画半透明矩形。
- 步骤标记选中后只显示四个角点并保持圆形等比缩放；矩形、椭圆、画笔和打码等对象提供八向自由缩放。
- 缩放矩形、椭圆、直线、箭头和画笔时只改变对象几何范围，不随拖动改变描边粗细；文字缩放按高度调整字号。
- 编辑过程保留可调整对象；复制、保存、置顶和历史输出均合成为普通图像，不包含可恢复的标注图层或隐藏原图。
- 输出尺寸、坐标和裁切须在同一渲染管线中计算，预览与导出不能分别维护两套不同规则。

### EDIT-04 圆角与阴影

- 圆角和阴影独立开关、可调整，默认关闭；统一应用于复制、保存和置顶结果。
- 圆角外保留透明背景；阴影需要扩大输出边界，不能被裁断；不叠加系统窗口阴影造成双阴影。
- 执行默认值：圆角半径按输出像素配置，最大为短边一半；阴影提供透明度、模糊和垂直距离，使用黑色阴影。
- 圆角通过选区右下角内部圆点直接拖动：向选区内拖动增大，向外拖动缩小，拖到零时关闭圆角；不在工具栏平铺圆角参数。
- 圆角拖动与选区边缘缩放分别命中，外观调整属于当前编辑历史，支持撤销、重做和取消拖动。
- 阴影设置从底部标注工具栏打开，不与右侧输出动作混排。
- 外观在原图裁切与标注合成后应用。除明确的外观扩边外，不无故改变输出分辨率。

## 5. 输出与置顶

### OUT-01 输出

- 工具栏独立提供「复制」「保存」「置顶」。执行默认值：空闲编辑态 Enter 复制，Command+S 保存；文字输入态不截获 Enter。
- 复制使用系统剪贴板中的标准图片表示，不依赖临时文件；保存输出 PNG，通过系统保存面板选择路径。
- 取消保存不算完成；复制、保存或置顶失败不能关闭编辑并丢失标注。
- PNG 编码与磁盘写入在后台执行，文件以原子方式提交；内存图片不无故落盘。

### PIN-01 悬浮图片

- 支持多张图片置顶、拖动、等比缩放、复制、保存和关闭。
- 第一批为合成后的图片，不支持恢复成原编辑会话；置顶后继续编辑单列后续能力。
- **每张置顶图支持透明度调节，用于查看下方内容。**
- 执行默认值：透明度范围 10%–100%，新建置顶图为 100%；按图片独立维护，关闭后不保存窗口透明度。
- 透明度只改变置顶显示效果，不改变复制、保存或历史图的像素；操作控件保持可见，不随图片一起淡出。
- 执行默认值：不提供鼠标穿透、跨桌面跟随或重启恢复置顶窗口；关闭置顶不删除已保存图片或历史记录。

## 6. 最近截图与自由拼图

### HIST-01 最近截图

- 默认关闭；开启截图功能后可启用记录，保留最近 50 张已完成截图，并支持单张删除和清空。
- 完成指复制、保存或置顶成功；取消、失败和未完成编辑不记录。
- 只保留合成后的 PNG 与必要索引信息，不保留原始屏幕大图和可编辑标注。
- 执行默认值：一个编辑会话只生成一条记录；从置顶或历史再次复制、保存不重复记录。
- 关闭记录不自动删除已有记录。第 51 条成功记录后淘汰最早的一条；仅删除应用管理目录中的历史文件，不碰用户保存的文件。
- 执行默认值：按完成时间倒序，提供缩略图、复制、保存、置顶、加入拼图、删除；首批不提供搜索或分类。
- 历史写入失败不能回滚已成功的复制或用户文件保存；显示具体失败原因，不虚报已记录。

### COLLAGE-01 自由拼图

- 可添加最近截图和本地图片，自由摆放、等比缩放、调整前后层级，支持横向／纵向排列。
- 输出为一张图，支持复制和 PNG 保存；取消保存仍保留画布。
- 执行默认值：本地输入支持 PNG、JPEG、HEIC，正确应用图片方向；不支持多页文档、动画或视频。
- 执行默认值：背景透明，按所有图片的外接边界导出；横排顶对齐、竖排左对齐，保留当前缩放，间隔 16 输出像素。
- 支持选择、移动、缩放、删除、撤销／重做；不在首批加入旋转、智能排版或项目文件保存。
- 执行默认值：删除历史记录不破坏已经加入画布的图片；拼图成功输出也可作为一条新的最近截图记录。

## 7. 滚动截图

### SCROLL-01 独立技术验证

- 先做用户手动纵向滚动、软件自动拼接；提供完成与取消。自动驱动滚动后续再做。
- 第一批验证 Safari、Chrome 的稳定静态页面；使用明确的本地长页面样本验证，不以「支持任意应用」作为首批承诺。
- 滚动截图不提供独立选区流程。用户先进入普通截图，识别窗口或手动框选后，通过工具栏“滚动截图”或 `⌃⌘R` 进入采集。
- 采集范围固定在一块显示器内，复用已经确认的选区，避免把工具栏等固定区域纳入；采集期间选区不得移动或改变尺寸。
- 选区旁显示可辨认的实时拼接预览，优先放在右侧、左侧、下方或上方，并避开目标应用窗口；侧边空间不足时先压缩预览，所有外部位置都无法容纳才悬浮在选区内部。
- 预览内容按完整长图等比 contain 缩放，长图增长时缩小整图而不是只显示底部切片。
- 采集时选区只显示滚动提示和左上角“完成”按钮；Enter 完成，Esc 取消，不显示带“继续／停止”的浮动控制面板。
- 支持向上和向下滚动拼接；方向变化时把新内容可靠拼接到顶部或底部。
- 必须处理重复帧；有可靠重叠才拼接，不能凭固定偏移硬接。重复帧与短暂不匹配不中断采集，向上和向下滚动均可可靠拼接；跳跃过大或重叠不可靠时继续等待稳定画面，采集失败时保留已拼接部分并用提示说明原因。帧数上限只计算有效拼接帧。
- 停止后在原选区位置和尺寸打开无边框长图编辑会话，不显示独立标题栏；复用普通截图的标注、外观、缩放、复制、保存、置顶和取消。选区固定不可再裁切，长图可滚动缩放访问全部内容。取消不保存、不记录历史。
- 固定页眉、动态内容、懒加载、横向滚动不是第一批保证范围；不能静默制造重复或缺失内容。
- 执行默认值：结果上限 4000 万像素、采集上限 100 帧；达到上限停止采集，允许检查和输出已完成结果。技术验证后可依据内存实测调整并同步文档。

## 8. 技术边界与统一验收

- 全局快捷键优先沿用原生 RegisterEventHotKey；不为了录入或应用切换默认要求辅助功能、输入监控。
- 图像捕获使用 ScreenCaptureKit；自由选区、窗口选择遮罩和像素图像编辑优先 AppKit 承载，设置继续 SwiftUI。
- 编辑源图、选区、标注对象是独立状态；以原图左上角为原点的像素坐标为统一模型，集中处理 AppKit 全局坐标和 Retina 比例转换。
- 窗口源图与显示器源图必须标识清楚，不能把屏幕裁切包装成独立窗口捕获。
- 简单设置用 UserDefaults；快捷键绑定和历史索引用版本化本地数据，原子写入；图片在 Application Support 专属目录管理。先用 JSON 和文件，不提前引入数据库。
- 每阶段要求 Debug / Release 构建通过、相关自动测试通过、完成列出的人工验收；无法验证的设备与系统必须记录，不把配置了最低版本当作实测。
- 普通截图不建立持续录屏；滚动采集结束必须停止流、计时器和后台任务。关闭编辑／置顶／拼图后释放对应图片。
- 为保证选区与源图像素保持一一对应，普通截图编辑不增加画布缩放；长截图编辑器因需访问超长内容提供缩放。若后续加入普通截图缩放，需先明确选区与标注坐标在缩放、平移和恢复原比例时的行为。
- 依赖顺序、任务边界及每项验收见 [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)。

## 9. 模块生命周期与共享动作

### MOD-01 模块范围与默认值

| 模块 | 默认 | 关闭后的结果 |
|---|---|---|
| 截图 | 关闭，升级时保留 | 停用截图、最近截图、拼图、滚动截图及对应快捷键／手势目标；关闭已完成的置顶窗口 |
| 快捷键 | 开启，升级时保留 | 释放 nylai 注册的全局键位，保留全部绑定 |
| 鼠标手势 | 关闭 | 移除事件 tap、监听、轨迹和当前会话；不拦截鼠标 |
| 剪贴板 | 关闭 | 停止读取变化、轮询和自动清理，关闭浮动历史面板；保留历史与置顶 |
| 窗口切换 | 关闭 | 移除键盘事件 tap、关闭切换面板并释放缩略图缓存；恢复系统切换键 |

- 设置统一提供五个模块开关；设置和退出始终可用。
- 全局快捷键模块开关就是原总开关，不能保存两份互相矛盾的状态。
- 模块开启意愿与实际运行状态分开；未授权或启动失败显示具体原因，不显示成运行中。
- 关闭不删除配置、历史、置顶或系统权限；重新开启按保存配置恢复。
- 剪贴板关闭时仍可在设置中查看和清理旧数据，不开放历史面板。

### MOD-02 共享动作与目标可用性

- 键盘、菜单和鼠标手势通过同一动作标识和执行入口工作。
- 目标模块关闭时，各入口都不得运行其动作；绑定或规则保留，并显示“目标模块已关闭”。
- 指向关闭模块的键盘绑定立即释放系统键位；重新开启后若被外部占用，显示真实注册失败，不静默换键。
- 关闭全局快捷键不禁止菜单截图、应用动作或手势发送组合键。
- 截图历史与剪贴板历史是独立数据集，清理一方不能删除另一方。

### MOD-03 截图独占交互

- 截图选择、滚动采集或长图编辑期间，不打开设置、最近截图、拼图或剪贴板面板，不执行应用切换手势。
- 鼠标手势不得捕获截图覆盖层或长图编辑器中的右键轨迹。
- 重复触发截图只返回当前会话；不创建第二个覆盖层。
- 截图自身保存面板、颜色选择器和权限提示仍可使用。
- 不锁住 macOS 系统级退出或强制退出；应用退出必须取消任务并释放窗口、tap 和注册。
- 非常规路径停止截图时直接取消未完成会话并清理，不新增保存确认框。

### MOD-04 停止与恢复

- 启动和停止必须幂等；重复停止、停止未启动服务不崩溃，不重复创建监听或计时器。
- 关闭鼠标手势时立即取消当前识别，不执行未完成动作，不残留右键按下状态。
- 关闭剪贴板后旧代次读取／解码／写入不得提交新记录；重新开启建立新基线。
- 睡眠期间不轮询、不采集；唤醒后重新建立基线和监听。
- 应用退出后不保留事件 tap、采集任务、轮询、计时器或悬浮窗口。

## 10. 鼠标手势

### MG-01 路径与规则

- 按住右键绘制 1～4 段上、下、左、右方向，松开后执行；连续同向合并。
- 默认移动超过 12 屏幕点进入手势，方向变化经过最小距离后才增加段。
- 支持新增、编辑、删除、启停规则，录制路径、选择动作、轨迹开关和应用作用域。
- 执行动作：nylai 已实现功能、启动／切换应用、发送一次组合键。
- 不做左键／中键重映射、滚轮增强、触控板手势、任意图形或宏。

### MG-02 普通右键共存

| 状态 | 松开右键后的行为 |
|---|---|
| 未进入手势 | 产生一次正常右键菜单 |
| 匹配有效规则 | 执行一次动作，不弹菜单 |
| 有规则但路径无匹配 | 不执行，不弹菜单 |
| Esc 取消 | 不执行，不弹菜单 |
| 模块关闭／应用禁用／无可用规则 | 原始鼠标事件直接通过 |

- 恢复菜单的合成事件必须带来源标记，不能再次触发识别或形成 down/up 循环。
- 手势期间不吞左键和滚轮；Esc 通道只服务当前会话。
- 开始在何时冻结目标应用和规则快照；切应用、睡眠、tap 停用、权限撤销或模块停止即取消。
- 仅被动监听不能阻止菜单，不能以“菜单和动作同时发生”冒充完成。

### MG-03 作用域与冲突

优先级固定为：**应用禁用名单 > 应用专属规则 > 全局规则**。

- 禁用名单内不识别、不拦截。
- 当前应用存在该路径专属规则时，即使停用或目标不可用，也不回落执行同路径全局规则。
- 同一作用域同一路径不可重复；不同应用可配置相同路径的不同动作。
- 一次手势最多执行一个动作。
- 发送组合键不受全局快捷键模块开关控制，只要求目标应用仍是开始手势时的前台应用且系统允许发送事件。

### MG-04 权限与验证边界

- 主动事件 tap 需要辅助功能；只在开启模块且存在可用规则时请求，每次应用启动最多触发一次系统授权提示。拒绝后设置页提供系统设置入口，重试不能重复堆叠系统弹窗。
- 无法创建 tap 时显示失败并允许正常使用鼠标，不要求 root、驱动或系统保护修改。
- 真实 tap、两个普通 GUI 应用中的右键菜单恢复、Esc、左键／滚轮、睡眠与权限撤销必须人工验收。
- 自动状态机测试不能替代真实系统输入验证。

## 11. 剪贴板历史

### CB-01 内容与监听

- 默认关闭；开启后记录纯文本和图片，不记录富文本格式、文件引用、文件内容或多媒体。
- 每 500ms 检查 changeCount；只在变化后读取，读取前后校验版本。
- 开启、重启恢复和唤醒时建立当前基线，不补录停用或睡眠前内容。
- 多项复制按系统条目顺序读取支持项；同一项有图片和文本时优先图片。
- 文本上限 1 MiB UTF-8；图片编码上限 20 MiB、像素上限 4000 万。超限或读取失败不生成空记录。
- 权限拒绝后停止轮询并显示实际状态，不持续读取触发提示。

### CB-02 数据与去重

- 历史、置顶和配置本地持久化；图片正文、缩略图和索引都在应用专属目录。
- 文本按原始 Unicode UTF-8 精确去重；图片按尺寸和统一像素表示去重。
- 相同内容更新最后复制时间和最新来源；普通记录移到顶部，置顶记录不改变置顶顺序。
- nylai 自己的历史回写不生成重复记录；截图复制可以由已开启的剪贴板正常记录。
- 使用版本化索引和原子提交，不静默重置损坏数据。

### CB-03 数量、清理与置顶

- 普通记录默认最多 200 条，可配置 1–5000；置顶不计入上限。
- 按天清理默认关闭；启用默认 30 天，范围 1–365，只清理普通记录。
- 启动／开启、成功记录、策略变更和开启期间每小时执行清理；停用或睡眠不唤醒设备。
- 降低上限、取消置顶后立即按策略清理。
- “清空普通记录”保留置顶；“清空全部”单独命名并确认。
- 删除只影响 nylai 管理的数据，不修改系统剪贴板当前内容或用户文件。

### CB-04 屏蔽与敏感内容

- 应用禁用名单按 bundle ID 保存；加入后不删除既有记录。
- 来源由 `org.nspasteboard.source` 和观察时前台应用尽力推断；任一命中名单即跳过。
- 两者都未知且启用名单时默认跳过。
- Concealed、Transient、AutoGenerated 内容在读取正文前忽略。
- macOS 不保证来源可信，不承诺百分百屏蔽后台写入，不用文本猜测所有密码。
- 不记录正文或按键到日志，不上传。

### CB-05 历史面板

- 菜单、已配置快捷键或手势打开浮动历史；新动作初始不绑定。
- 搜索文本和来源名称；图片只搜索来源。
- 点击条目复制并关闭；写入失败保留面板并显示原因。
- 置顶、删除和直接粘贴是独立操作，不误触发复制。
- 方向键选择、Enter 复制、Esc 关闭；搜索输入优先接收字符。
- 直接粘贴记住打开面板前的目标，写入后关闭面板、激活并验证前台身份，再发送一次 `Command + V`。
- 目标退出、前台改变、权限不足或剪贴板被竞争改写时停止，不向其他应用误发；失败后用户仍可手动粘贴。

## 12. 跨模块验收

- 五个模块反复启停不叠加 tap、计时器、轮询或窗口。
- 截图关闭但其他应用复制的图片仍可由剪贴板记录。
- 剪贴板关闭但截图复制仍正常写入系统剪贴板。
- 全局快捷键关闭后菜单、手势和应用动作仍可工作。
- 截图独占期间不能打开剪贴板历史或设置，手势不拦截截图。
- 清空截图历史不删除剪贴板数据，反之亦然。
- 睡眠唤醒、目标应用切换、权限撤销和应用退出后无旧任务回写或资源残留。
- 关闭窗口切换后 `⌘Tab` 立即恢复系统行为；切换会话中关闭模块、截图或进入睡眠不得执行遗留选择。
- 全局快捷键模块关闭和标题快捷键录入不改变窗口切换模块的运行状态。
- 真实系统权限、右键菜单、组合键发送、剪贴板来源和直接粘贴必须用本机实测记录；fake 测试不能标记为真实通过。


## 13. 应用分组窗口切换（首版代码完成，待真实系统验收）

### WS-01 核心模型与首版范围

- 使用同一全屏面板的两层结构：上方紧凑排列大图标、窗口数角标和图标下方常驻应用名，下方按窗口数量自适应列数并直接显示所选应用的窗口预览；无需先激活应用或进入下一层页面。macOS 26 及以上面板背景使用系统 Liquid Glass，旧系统使用 HUD 模糊材质。
- `⌘Tab` 始终切应用，`⌘` 加反引号键始终切应用内窗口，不随窗口数量改变语义。不采用所有窗口默认平铺。
- 首版覆盖当前桌面的普通应用窗口和最小化窗口，使用缓存缩略图；多桌面、全屏和隐藏窗口的恢复列为后续兼容扩展，不宣称首版覆盖。
- 执行默认值：包含当前可见桌面的各显示器窗口，面板在触发前鼠标所在显示器显示；当前桌面无普通窗口的常规 GUI 应用仍可作为应用项，只显示图标和名称，松键只激活应用、不新建窗口。
- 排除桌面、菜单、系统浮层及 nylai 的切换面板、截图覆盖层和置顶图，不把浏览器标签页视为独立窗口。
- 全窗口平铺、标题搜索、自定义分组、窗口排列和关闭窗口不纳入首版。

### WS-02 键盘与确认

| 操作 | 行为 |
|---|---|
| 按住 `⌘` 后按 `Tab` | 打开面板并选中上一个应用；继续按 Tab 切到下一个应用 |
| 保持 `⌘`，按反引号键 | 在当前所选应用的窗口间前进；不会切换应用 |
| 保持 `⌘`，按 `← / →` | 在当前所选应用的窗口间后退／前进 |
| 直接按 `⌘` 加反引号键 | 打开当前应用窗口预览，选中该应用的上一个窗口；继续按反引号键循环 |
| 点击上方应用 | 立即选中该应用并显示其窗口；随后按 Tab 从该应用继续应用级循环 |
| 点击下方窗口 | 立即确认并切换到该窗口 |
| 松开 `⌘` | 确认一次，激活所选窗口或无窗口的应用项 |
| `Esc` | 取消，不改变原前台窗口；随后松开 ⌘ 不再确认 |

- 执行默认值：Shift+Tab、Shift+反引号键分别反向循环应用、窗口；单窗口应用直接选中该窗口，当前应用无窗口时直接窗口入口不执行切换。
- 快速按下并松开 `⌘Tab` 仍回到上一个应用，不能等待缩略图生成后才激活；直接窗口入口同样支持最近两个窗口快速往返。
- 预览选择不实际激活其他应用或窗口，确认前保持原工作上下文。
- 键盘自动重复可以推进选择，但松键只确认一次；取消、失焦、睡眠或模块停止后不能执行遗留选择。

### WS-03 排序、预览与失效处理

- 应用与各应用内窗口分别按最近使用顺序排列；切换到应用时默认选中它最近使用的窗口。
- 会话打开时冻结排序；刷新预览或观察到使用变化不能移动选择位置。会话外更新最近使用记录，切换面板本身不计入历史。
- 缩略图保持宽高比并显示短标题；应用项紧凑显示大尺寸真实图标、图标下方常驻名称和窗口数角标。窗口很少时放大预览，窗口变多后自适应增加列数；仍超出屏幕时滚动展示，确保选中项可见。
- 使用内存缓存、按需刷新和有界捕获，不为所有窗口持续录制；窗口图像不落盘、不写入截图或剪贴板历史。
- 预览尚未就绪时先显示图标和标题；捕获失败不伪造预览。确认时重新校验应用与窗口身份，目标消失时不误激活同名窗口或其他应用。
- 执行默认值：目标窗口消失后移除该项并保留其他项顺序；应用仍有窗口则选择相邻项，否则回到其应用项。确认阶段目标已失效时取消该次切换。

### WS-04 模块、权限与系统共存

- 作为独立的“窗口切换”模块，首版默认关闭；开启后才接管 `⌘Tab` 和 `⌘` 加反引号键，关闭或退出立即恢复系统处理。首次安装时快捷键默认开启，其余四个功能模块默认关闭。
- 不依赖全局快捷键模块总开关；专用会话处理与普通 Carbon 动作注册分开，统一处理按下、连按、修饰键释放、取消和资源释放。
- 窗口枚举、焦点激活与缩略图捕获需要的实际权限及 API 先在 WS-T01 验证，按需申请；不能复用截图当前桌面候选列表便宣称覆盖所有窗口。
- 启用失败或权限撤销显示实际原因，停止接管系统键；不能出现按键被吞但自定义面板不可用的状态。不修改系统保护或要求 root。
- 截图选择、滚动采集、长图编辑及快捷键录入期间暂停自定义接管，不叠加切换面板；系统级退出、锁屏与强制退出保持可用。
- 与鼠标手势共享权限状态但不共享会话；模块停用、睡眠、事件监听失效和应用退出时取消会话、关闭面板、释放捕获任务与缓存。

### WS-05 验收边界

- 人工覆盖：两应用快速往返、同应用双窗口往返、跨应用后选指定窗口、Shift 反向、单窗口／无窗口、Esc 后松键、长按和目标关闭。
- 验证覆盖窗口被遮挡时仍有正确预览、窗口数超出面板时选择可见、不同键盘布局下反引号显示与键码处理。
- 验证权限拒绝／撤销、模块反复启停、截图与录入互斥、睡眠唤醒、异常退出后系统切换器可用；多显示器需实机记录，无设备标记未验证。
- 单独测量冷／热启动面板耗时、确认切换耗时、内存与空闲 CPU；WS-T01 记录基线，优化后用同条件复测，不以界面出现代替切换成功。
- 跨桌面、全屏与隐藏窗口恢复不作为首版通过依据，也不标记为已支持；最小化窗口应恢复并激活。
