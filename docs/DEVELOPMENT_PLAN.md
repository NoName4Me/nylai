# 可执行开发计划

依据：[REQUIREMENTS.md](REQUIREMENTS.md)。更新：2026-11-02。

当前所有下列任务均为**未开始**。本次只交付规格和计划，不授权开发模型自动连续实现全部阶段。

## 1. 执行方式

一次只执行一个任务 ID，先读取对应需求条款、依赖任务结果及目标代码。若依赖未通过验收，停止该任务，说明具体缺口；不要自行补出产品决策。

每个任务交付：修改文件、行为变化、自动检查结果、人工验收步骤、尚未验证项。更新任务状态必须依据实际结果。涉及真实屏幕录制授权时交给用户操作，不自动改变系统隐私权限。

- 不重写整个工程，不为了未来功能提前引入插件框架、通用事件总线、数据库或第三方依赖。
- 接口名称和新增文件路径在本文中是建议边界；可依现有代码小幅调整，但不能扩大任务范围。
- 需求规格定义最终行为；当前代码是实现基线，不是最终产品需求。遇到矛盾先报告，不默默改变需求。
- 「执行默认值」可以直接用于该任务；有实质冲突时仅询问最关键的问题，不在未确认情况下更改已确认行为。
- 一个任务完成不代表整个截图编辑器完成；未实现功能不能通过按钮、假数据或成功提示伪装可用。
- 不向 GitHub 推送。若创建本地提交，作者与提交者必须使用仓库本地 NoName4Me 身份，不修改全局配置。

通用检查命令，在仓库根目录执行：

```sh
xcodebuild -project nylai.xcodeproj -scheme nylai -configuration Debug -destination 'platform=macOS,arch=arm64' -derivedDataPath build test
xcodebuild -project nylai.xcodeproj -scheme nylai -configuration Release -destination 'platform=macOS,arch=arm64' -derivedDataPath build build
git diff --check
```

修改了行为时添加针对需求的测试；仅文档修改不重复构建。人工验收不能被 mock 测试替代；没有设备时记录「未验证」。

## 2. 可复用基线

| 现有代码 | 可复用部分 | 后续边界 |
|---|---|---|
| `AppDelegate`、`StatusBarController` | 菜单与动作入口 | 不继续把所有功能逻辑塞进 AppDelegate |
| `CarbonGlobalShortcutRegistrar` | 独占注册、回调路由、资源释放 | 需支持按单个注册注销，才能安全换键 |
| `GlobalShortcutController` | 固定动作注册及错误状态 | 改为由绑定配置驱动，不维护两套注册源 |
| `ScreenCaptureService`、`ScreenCapturing` | 显示器图像捕获、权限错误 | 扩展源类型，不把窗口捕获实现成显示器裁切 |
| `ScreenshotController` | 单任务、错误、取消 | 拆开捕获、编辑、输出，不再捕获后立即保存 |
| `PNGScreenshotSaver`、`PNGImageWriter` | 保存面板、后台 PNG 和原子写入 | 取消保存必须返回现有编辑会话 |
| `SettingsWindowController`、`SettingsView` | 原生设置窗口 | 增加导航和快捷键页面，保留原有设置 |

当前已有 14 项测试，以及用户确认的 `⌃⌥N` 设置呼出、`⌃⌥S` 主显示器 PNG 保存。后续重构须保留这些回归检查；截图进入编辑的行为改变在 C-05 正式切换。

## 3. 阶段 H：全局快捷键配置（优先交付）

### H-01 绑定模型与本地存储

- 依据：HK-01、HK-03。依赖：无。
- 新增版本化绑定数据：稳定 ID、动作、可空快捷键、条目开关；应用动作另含 bundle ID、路径和再次触发隐藏开关。总开关单独存储。
- 提供可注入存储位置的读写组件，使用原子保存；迁移当前固定的 N / S 默认值。首次初始化与用户清空必须可区分。
- 不注册系统快捷键、不做录入控件、不启动应用。
- 验收：首次默认、清空后重启、总／单项开关往返、应用动作往返、损坏文件与未知版本保留原数据、写入失败不替换原配置。

### H-02 注册服务支持单项替换和回滚

- 依据：HK-03。依赖：H-01。
- 为注册返回不透明标识，新增单项注销；保留全部注销与现有资源清理。不要把 Carbon 指针暴露给设置 UI。
- 建立单一绑定运行服务，负责配置与实际注册状态；应用内重复检查使用标准化组合，不依赖显示字符串。
- 活跃键位修改先尝试新键，失败保留旧键；持久化失败撤销新注册，保留原配置和可恢复的旧注册。注销／恢复异常必须显示实际失败状态，不能吞错并宣称成功。
- 总开关恢复采用逐条结果；停用项不持有系统注册。移除原固定控制器的重复注册路径。
- 验收：使用 fake 注册器覆盖新注册失败、存储失败、注销失败、恢复失败；真实系统覆盖冲突、单项注销不影响其他动作、退出释放。失败后不能出现未显示的双重有效动作。

### H-03 原生快捷键录入控件

- 依据：HK-02、HK-03。依赖：H-02。
- 使用设置窗口内的本地键盘事件实现录入；显示可读组合，支持取消、清除和非法输入反馈。
- 明确进入／退出录入时的注册处理策略，确保原来已绑定的组合也可以录入，且不会触发截图或应用切换。所有退出路径恢复运行状态。
- 不使用全局原始键盘监听，不申请辅助功能／输入监控。若本地方案受系统保留键限制，反馈限制，不换成悄悄申请新权限的方案。
- 验收：普通组合、Shift 叠加、仅修饰键、非法按键、Esc、Delete、已有绑定组合、焦点离开、关闭窗口；切换输入源后显示刷新且物理键位不变。

### H-04 内部功能配置页

- 依据：HK-01～HK-03。依赖：H-03。
- 设置增加快捷键页；显示内部动作、录入控件、独立开关、总开关、实际注册状态、失败原因与重试。
- 接入现有「打开设置」「截取主显示器」，默认 N / S 保持；修改自动应用，不增加单独保存按钮。
- 不提前加入尚不可用的编辑、历史或拼图动作；本任务不增加应用选择器。
- 验收：修改、清除、重启恢复、总开关、单项开关、重复冲突与外部占用；失败时 UI 和实际键位一致。

### H-05 应用动作与选择器

- 依据：HK-04。依赖：H-04。
- 「应用」分组支持选取 `.app`、一应用一绑定、删除、重新定位应用，以及独立的再次触发隐藏开关。
- 抽出可测试的应用启动／激活适配器，按需求状态表执行；对同一目标尚未完成的启动合并触发。
- 不实现窗口枚举、窗口排列或辅助功能驱动的应用控制。
- 验收：fake 覆盖四种状态、隐藏开关、启动失败和重复触发；长按不重复切换；人工用至少两个普通 GUI 应用验证启动、后台激活、前台隐藏及返回、开关关闭后保持前台、应用缺失与重定位。

### H-06 快捷键阶段验收

- 依赖：H-05。
- 完成 Debug 测试、Release 构建及完整人工检查；记录键盘布局和实际系统版本。
- 验收总表：两类动作均可配置；重启保留；清空不复活；停用释放；应用内重复可见；外部占用不破坏旧配置；录入不触发动作；退出释放；不要求额外隐私权限。
- 交付：更新 README、ROADMAP 和实际架构说明。用户验收前不自动进入截图编辑开发。

## 4. 阶段 C：截图选择和编辑基础

### C-01 独立窗口捕获技术验证

- 依据：CAP-03。依赖：H-06。
- 在现有捕获服务旁验证 ScreenCaptureKit 独立窗口图像，不搭建完整编辑器。
- 用两个相互遮挡的普通窗口验证：结果只含目标窗口、不含遮挡窗口，标题栏和阴影符合约定。记录 macOS 14 API 可用性、输出尺寸及失败条件。
- 同时验证候选窗口前后关系来源；若 API 不能提供可靠顺序，先报告可行方案与权限代价，不申请辅助功能自行绕过。
- 验收：真实遮挡场景的图像证据和尺寸记录；此项失败时不进入 C-04，不降级冒充真正窗口截图。

### C-02 图像源、坐标与会话模型

- 依据：CAP-01～CAP-04、EDIT-02、统一技术边界。依赖：C-01。
- 建立显示器源／窗口源、原图像素尺寸、像素选区和标注集合的会话模型。显示器源记录全局 frame 与像素比例；窗口源独立记录自身范围。
- 集中实现屏幕全局坐标、AppKit 窗口坐标、原图左上角像素坐标的转换；不在每个手柄和绘图工具里重新计算。
- 建立最小会话状态：选择中、编辑中、输出中、结束；文本／绘图拖动属于当前编辑操作，取消优先结束当前操作。
- 不实现标注工具和历史保存。
- 验收：1×／2×比例、负坐标屏幕、上下排列屏幕、边界与 1 像素选区、选区移动不改变标注坐标；用确定性几何测试验证。

### C-03 冻结覆盖层与区域选择

- 依据：CAP-01、CAP-02、CAP-04。依赖：C-02。
- AppKit 覆盖层显示鼠标所在屏幕的一次捕获；拖出区域，松开后可移动及八方向调整，提供屏幕内可见工具栏位置。
- 只实现选区与 Esc，不画标注、不接入输出；再次触发回到现有会话。取消和切出清理窗口、鼠标状态与图片引用。
- 验收：拖动各方向、屏幕边缘、极小区域、调整后移动、零面积、Esc、再次触发、切换应用；真实多屏／Retina 无设备则标为未验证。

### C-04 窗口自动识别与源切换

- 依据：CAP-03。依赖：C-03，且 C-01 已通过。
- 悬停命中候选窗口并高亮，点击后采用真正窗口源；支持返回选择并切换自由框选。窗口源只能裁切其自身图像。
- 目标在捕获前消失／最小化时给出恢复路径，不错误选择其他窗口；排除自身和不支持的跨屏窗口。
- 本任务不实现 UI 控件识别、不捕获后台进程的所有窗口列表作为产品入口。
- 验收：遮挡窗口输出、重叠命中、桌面／自身排除、窗口关闭、切换模式、窗口边界裁切。

### C-05 无标注的编辑输出闭环

- 依据：OUT-01、CAP-04。依赖：C-04。
- 将现有主显示器直接保存流程切换为整图选区编辑；接入复制、PNG 保存和 Esc；新交互截图动作此时加入快捷键目录，初始未绑定。
- 取消保存／写入失败返回原会话，成功输出关闭；底图裁切与预览一致，工具栏不入图。
- 暂不提供尚未实现的置顶按钮。复用后台 PNG 写入，不新增并行保存实现。
- 验收：主屏／区域／窗口均可输出；边缘像素与尺寸正确；复制可粘贴到系统应用；取消保存保留选区；失败可重试；无活动任务残留。

## 5. 阶段 E：标注、渲染与外观

### E-01 对象选择与撤销基础

- 依据：EDIT-02、CAP-02。依赖：C-05。
- 建立可独立于视图测试的标注对象、命中、选择、移动、删除与编辑历史；先只使用矩形对象跑通。
- 将裁切变化纳入历史；一次拖动只提交一次撤销；撤销记录不得为每次操作复制整幅原始图像。缩小选区仅裁切显示，不删除源数据。
- 验收：操作序列撤销／重做恢复一致；撤销后新操作切断重做分支；缩小再扩大能恢复完整标注；对象选择不误拖选区。

### E-02 几何线条工具

- 依据：EDIT-01、EDIT-02。依赖：E-01。
- 完成矩形、椭圆、直线、箭头及颜色、粗细、实／虚线；支持对象修改与逐工具默认样式保存。
- 不加入画笔、文字或步骤编号。对预览和导出复用同一对象模型和路径构造。
- 验收：端点、角点、命中、越界裁切、样式修改、重启后样式保留；像素渲染样例覆盖四种工具与虚线。

### E-03 自由画笔

- 依据：EDIT-01、EDIT-02。依赖：E-02。
- 普通画笔轨迹、粗细、颜色、线型、整体移动与缩放；长轨迹不得造成明显输入阻塞。
- 不实现记号笔和毛笔；完成绘制才形成一个可撤销对象。
- 验收：短点击、快速连续路径、轨迹边界、整对象移动缩放、撤销与导出。

### E-04 文字与步骤编号

- 依据：EDIT-01、EDIT-02。依赖：E-03。
- 支持多行文字的编辑／提交／取消、颜色字号与对象移动；步骤自动编号与删除不重排。
- 验收：中文输入法合成期间不截获 Enter；Command+Enter 提交；空文本；Esc；字号修改；步骤删除／新增／撤销序列。

### E-05 两类打码

- 依据：EDIT-03。依赖：E-04。
- 完成矩形像素马赛克、模糊、区域调整和强度；修改或删除对象时能从源图重新渲染。
- 输出为处理后的合成图，不嵌入原图、图层或隐藏原始缩略图。
- 验收：真实像素变化；移动打码后原区域恢复预览；裁切边缘、撤销和导出结果；不能以透明色块替代。

### E-06 圆角、阴影与统一渲染

- 依据：EDIT-04、OUT-01。依赖：E-05。
- 完成外观开关和参数；统一「源图裁切 → 标注 → 圆角与阴影扩边 → 输出」的图像管线，服务复制、保存与后续置顶。
- 验收：默认关闭时尺寸不变；透明圆角不变黑；阴影四边不裁断；导出、剪贴板和预览在相同设置下匹配。
- 交付截图编辑阶段验收：三种源、八类标注、对象编辑、选区调整、撤销重做、中文输入、保存取消与失败恢复。

## 6. 阶段 P：置顶、历史与拼图

### P-01 置顶图片及透明度

- 依据：PIN-01。依赖：E-06。
- 使用合成图创建可关闭的浮动窗口，支持多图、拖动、等比缩放、复制、保存；加入置顶输出按钮。
- 每图透明度滑杆 10%–100%，默认 100%；只影响图片显示，操作控件、保存图和复制图不变。
- 不恢复原标注，不做鼠标穿透、跨桌面跟随、重启恢复。
- 验收：两张图独立移动／透明度；缩放比例；透视下层；导出像素不受显示透明度影响；关闭后释放资源；不重复叠加阴影。

### P-02 最近截图

- 依据：HIST-01。依赖：P-01。
- Application Support 下建立应用专属历史目录、版本化索引和缩略图；只在输出成功后记录合成 PNG。
- 完成最近 50 张、开关、复制／保存／置顶、单张删除与清空；分页或按需加载图片，不一次解码全部原图。
- 将最近截图加入菜单及可绑定动作目录，默认不绑定。加入拼图入口等 P-03 完成后再显示。
- 验收：50→51 淘汰、取消不记录、一次会话一条、置顶重复复制不增条、记录关闭保留旧图、索引损坏、写入失败、用户文件不受删除影响。

### P-03 自由拼图

- 依据：COLLAGE-01。依赖：P-02。
- 新建独立画布，从历史或本地导入，支持移动、等比缩放、层级、删除、横排／竖排及撤销重做；复用图片渲染与输出基础能力。
- 历史图加入后由画布持有，不依赖历史文件永远存在；应用图片方向，正确处理透明边缘。
- 完成后加入拼图动作目录和历史「加入拼图」操作。不要提前加入占位入口。
- 验收：混合尺寸、重叠层级、负位置外接边界、横竖排、方向、删除源历史、取消保存保留画布、输出后记录一条历史。

## 7. 阶段 S：手动滚动、自动拼接

### S-01 可行性实验与资源预算

- 依据：SCROLL-01。依赖：P-03；先独立实验，不立即接入完整 UI。
- 准备确定性本地静态长页面，用 Safari、Chrome 验证截取帧、重复帧判定、纵向位移估计与重叠匹配。采集不包含自身控制窗口。
- 记录拼接正确性、耗时、内存，以及固定页眉、动态内容、大跨度滚动、反向滚动的失败表现。
- 通过标准：在两种浏览器的测试页中，最终图没有重复／缺失行，重复帧不增长；无可靠重叠时能拒绝拼接。
- 未通过时报告阻碍，不降低为固定偏移拼接，也不宣称支持滚动截图。

### S-02 有界拼接组件

- 依据：SCROLL-01。依赖：S-01 通过。
- 从 UI 分离帧接纳／拒绝、重叠裁切和拼接结果；限制帧数、像素量与同时解码的图片数量。
- 验收：重复帧、正常重叠、反向、大跨度、相似重复内容、取消、限额；拒绝时保留已完成结果而不损坏它。

### S-03 采集交互与编辑接入

- 依据：SCROLL-01。依赖：S-02。
- 支持选择固定区域、开始、用户滚动、暂停原因、停止与取消；停止后将长图作为编辑源，复用裁切、标注、输出；使用可滚动、可缩放的编辑窗口访问整幅长图。
