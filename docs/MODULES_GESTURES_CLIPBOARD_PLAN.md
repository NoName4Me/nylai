## 2. 模块开关

### MOD-T01 配置与状态模型

- 依据：MOD-01。依赖：当前在做的原计划任务结束、可运行基线明确。
- 增加稳定模块 ID、启用意愿与实际运行状态；设置提供四个模块开关，基础设置／退出不可关闭。
- 将已有快捷键总开关映射为同一模块状态，不保存两份独立总开关。截图保留现有行为，新鼠标／剪贴板默认关闭。
- 不启动鼠标监听或剪贴板轮询，不提前展示不存在的功能面板。
- 验收：初始值、迁移旧配置、重启保留、实际失败与已开启状态不同、总开关只有一个数据来源。

### MOD-T02 共享动作与入口可用性

- 依据：MOD-02。依赖：MOD-T01。
- 从键盘绑定运行服务中提取可复用动作执行入口；菜单、键盘与未来手势共同查询目标模块可用性。
- 截图关闭时停用其键位和菜单动作但保留绑定；键盘模块关闭时不禁用菜单截图和公共应用执行器。
- 本任务不实现手势识别或剪贴板 UI，不绕过键盘录入原有的动作抑制规则。
- 验收：模块开关矩阵、目标关闭不占键、目标恢复时占用冲突、菜单仍可工作、绑定未丢失；对调用入口直接做单元测试，不能只灰化按钮。

### MOD-T03 生命周期与截图独占

- 依据：MOD-03、MOD-04。依赖：MOD-T02。
- 每模块提供幂等启动／停止路径；先接现有截图、置顶及快捷键，未来模块使用同一生命周期约束。
- 截图选择／编辑期间不接受设置、应用切换和其他面板动作；保存／颜色面板可用；正常完成／取消后恢复。触发前已显示的本应用窗口保留在截图源中，截图控制浮层不进入输出。
- 空闲时关闭截图清理其置顶窗口，保留历史和配置；异常外部停止取消会话而不输出。不实现编辑中关闭模块的保存确认框。
- 验收：所有入口被约束、重复触发只有一个会话、退出恢复、停止幂等、关闭后无注册／窗口／任务残留；不得拦截 macOS 系统退出能力。

## 3. 鼠标手势

### MG-T01 真实输入与权限技术验证

- 依据：MG-02、MG-04。依赖：MOD-T03。
- 独立验证必要的主动事件 tap、普通右键的完整恢复、轨迹覆盖层与一次动作派发；只做固定示例，不先建完整规则 UI。
- 验证实际权限组合，记录系统版本；仅在用户主动使用时请求。不得依赖 root、驱动或系统保护改动。
- 自行生成的回放鼠标／键盘事件必须带来源标记；回调避免 UI／磁盘耗时。验证 tap 超时、系统停用、权限撤销后的输入恢复。
- 人工验收：至少两个普通 GUI 应用；普通右键一次菜单、有效手势一次动作且无菜单、无匹配无动作无菜单、Esc 取消、左键／滚轮不受影响、关闭后右键即时恢复。
- 未通过不得进入 MG-T02，不能降级成同时弹菜单和执行动作后宣称完成。

### MG-T02 规则、方向识别与作用域

- 依据：MG-01、MG-03。依赖：MG-T01 通过。
- 纯模型保存版本化规则、路径、动作、启用状态和应用作用域；持久化可注入路径，沿用原子写入与错误保留规则。
- 从轨迹生成最多四段方向；集中处理阈值和抖动；规则解析遵循禁用名单、应用专属、全局的顺序。
- 不做任意图形、滚轮或按键重映射，不在本任务增加系统全局监听。
- 验收：四方向、组合、连续同向合并、抖动、过短、过多段、同作用域重复；专属停用不落回全局、未知路径、禁用应用、不可用目标、配置往返。

### MG-T03 设置与动作接入

- 依据：MG-01、MG-03。依赖：MG-T02。
- 设置增加规则列表、应用选择／禁用名单、本地录制区域、动作配置和轨迹开关；录制不执行绑定动作。
- 接入已实现的内部功能、共享应用动作、单次组合键发送；应用目标的前台隐藏开关每规则独立保存。
- 不要求创建键盘绑定才能绑定手势；关闭键盘模块后鼠标规则仍可使用。无权限或目标变化不发送组合键。
- 验收：配置重启恢复、修改立即生效、重复拒绝、轨迹关而识别仍工作；应用前台／后台／未运行三态、目标关闭、发送一次组合键。

### MG-T04 全局生命周期与阶段验收

- 依据：MOD-03、MOD-04、MG-02。依赖：MG-T03。
- 正式接入模块启停与截图独占；手势开始时冻结规则作用域和目标，过程中切应用／睡眠／权限变化／停用立即取消。
- 验收：反复开关不叠加 tap；关掉后无后台输入监听；拦截一半后停用不会卡住右键；原生菜单、拖动、滚轮、截图编辑、快捷键录入都不被误触发；tap 恢复不补旧动作。
- 交付实测权限说明与未验证设备清单，用户验收后才能称鼠标手势首批完成。

## 4. 剪贴板

### CB-T01 系统读取、来源与访问控制验证

- 依据：CB-01、CB-04。依赖：MOD-T03；可在用户调整顺序后独立于鼠标 UI 执行。
- 验证 NSPasteboard changeCount 读取、文本／图片／多项类型、变化期间读失败，以及本机实际访问控制。
- 验证 source 类型约定与前台应用估计的差异，覆盖后台写入、快速切应用、来源未知、敏感／临时标记；不得以一次前台应用查询宣称真实来源可靠。
- 对 accessBehavior 等较新 API 作最低 macOS 版本分支；拒绝时显示未运行状态，不不断读取以触发授权提示。
- 本任务不存正式历史、不建完整面板。记录读取和直接粘贴分别需要哪些权限，不捆绑授权。
- 验收：本机可重复的结果记录；不能可靠识别的来源明确保留限制，不绕过权限或申请无关能力。

### CB-T02 数据、去重和清理模型

- 依据：CB-02、CB-03。依赖：CB-T01。
- 建立版本化索引、小型元数据、独立正文／图片文件和缩略图；注入存储位置与时钟，原子提交，不一次解码所有图片。
- 实现文本／图片内容标识、普通记录与置顶、更新最后复制时间、200 条普通上限、可选按天清理、单删／清普通／清全部。
- 同一顺序执行记录与清理，删除后不能被排队旧写入复活；不调用系统剪贴板清空 API，不删除应用目录外文件。
- 验收：重复更新、置顶排序、200→201 淘汰、置顶不占数、取消置顶后的淘汰、过期边界、更新时间重置、关闭时间清理、缩减上限、重启、损坏与写失败。
- 自动覆盖：默认 200→201、置顶不占普通上限、过期精确边界、重复刷新时间／来源与排序、未知来源黑名单跳过、命中不新增／不刷新、复制失败保留面板、图片搜索只匹配来源。

### CB-T03 有界监听与黑名单过滤

- 依据：CB-01、CB-04、MOD-04。依赖：CB-T02。
- 模块开启后以单一轻量计时器观察变化，开启／恢复时只建立基线；读取前后核对版本，后台做有界解码和去重。
- 先过滤类型标记、来源与黑名单，再提交内容；自写历史回放不会刷新记录，截图写入可正常记录。
- 关闭／睡眠取消计时器；停止代次检查覆盖读取、解码、写入，旧代次不得提交。开启期间按策略执行自动清理。
- 验收：停用不读、开启不补旧内容、观察版本竞争、超限跳过、黑名单无新增／更新时间、未知来源策略、敏感标记、自写无循环、睡眠唤醒、停止时正在解码或写入。
- 实现注入式前台应用与通知中心，睡眠／唤醒测试不依赖真实系统状态；关闭时旧代次仍不能提交。

### CB-T04 设置、历史面板与复制

- 依据：CB-03、CB-05。依赖：CB-T03。
- 设置提供普通上限、自动清理／天数、应用黑名单、旧数据管理；限额完成输入后才应用，不能逐字符淘汰。
- 浮动面板分置顶与普通、搜索文本及来源、鼠标／键盘选择、复制后关闭；置顶和删除操作不触发复制。加入菜单及可绑定动作目录，初始未绑定。
- 模块关闭时面板不可打开，设置仍可查看及清理旧数据；清普通与清全部准确区分。
- 验收：重启保留、分组和搜索、清理置顶保护、限额输入中途不删除、复制失败保留面板、复制成功关闭；清历史后系统当前剪贴板内容不变。

### CB-T05 可选直接粘贴

- 依据：CB-05。依赖：CB-T04；优先复用已验证的组合键发送适配器，不依赖鼠标模块必须开启。
- 独立操作：记录原目标、复制条目、关闭面板、激活并验证目标后发送一次粘贴，不从列表选中动作自动发出。
- 验证需要的事件发送权限，仅在用户请求直接粘贴时引导；不影响基础复制功能。
- 原目标退出／改变、权限不足、剪贴板被其他进程改写时停止，不误粘贴给别的应用；不声称能确认所有目标应用已经接收内容。
- 验收：两个应用间的目标恢复、文本／图片粘贴、未授权、目标消失、前台被第三方抢占、系统剪贴板竞争；失败后用户可手动粘贴所选内容。
- 面板关闭后的异步任务保留模型生命周期；自动测试覆盖关闭后仍收到目标改变失败反馈。

### CB-T06 跨模块与隐私验收

- 依据：全部 CB 条款及 MOD-01～MOD-04。依赖：CB-T05。
- 检查读取开关、持久化、删除一致性、日志无内容、系统访问控制和反复启停资源释放。
- 验收矩阵：剪贴板关闭但截图仍可复制；截图关闭但其他图片仍可记录；键盘关闭可用菜单／手势；截图独占中不能打开历史面板；清截图历史不清剪贴板，反之亦然。
- 检查历史／置顶重启、限额与过期、删除在途写入竞争、黑名单局限的实际表现；保留未覆盖系统／设备记录。
