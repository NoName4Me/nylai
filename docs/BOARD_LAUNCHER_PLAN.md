# 无限画布与 Launcher 实施计划

先交付 Board，随后在同一开发分支实现 Launcher。两者独立模块，默认关闭，关闭保留数据，复用现有快捷键和动作入口。保留自由拼图与剪贴板历史面板。macOS 14+、Swift 6、SwiftUI/AppKit、纯本地优先。

| 阶段 | 交付内容 | 验收 |
|---|---|---|
| B1 | 本地版本化数据、图片独立资源、多个画布与默认画布、自动保存、恢复视口 | 重启恢复、损坏文件不被覆盖、关闭模块保留内容 |
| B2 | 无限平移、光标中心缩放、适应全部、选择/移动/缩放、层级/锁定/编组、多选、撤销重做、吸附 | 负坐标、缩放后拖拽、键盘操作和多对象移动正确 |
| B3 | Markdown 便签、透明文字、Todo、图片粘贴与拖入、画笔/马克笔、橡皮、直线/箭头/矩形/椭圆 | 中英文输入、勾选、原图输出、图形编辑 |
| B4 | 画布/独立便签置顶（共享数据）、快捷记录、搜索并定位、OCR、选择或全部导出 PNG | 浮动编辑同步、导出边界、无需开启剪贴板即可粘贴 |
| B5 | 截图与剪贴板主动发送到指定画布、复用 OCR/钉图/标注 | 历史清理不丢已收藏内容；模块关闭无入口 |
| L1 | Launcher 面板、全局/专项检索、结果操作、快捷键与冲突提示 | Esc 恢复前台，键盘导航、中文输入法、关闭模块释放快捷键 |
| L2 | 应用/窗口/系统命令、拼音/缩写/模糊/别名、近期使用权重 | 精确匹配优先、可切换指定窗口 |
| L3 | 文件（Spotlight）/剪贴板/截图 OCR/画布内容的多来源检索 | 取消过期请求、结果定位/复制/预览、遵循模块开关 |
| L4 | Quicklink（URL、文件、目录、应用、参数化 URL），即时计算/单位/开发工具 | 配置持久化，参数安全编码 |
| L5 | 浏览器标签页/书签/历史，先验证 Safari 与 Chromium；其他浏览器按能力适配 | 权限按需申请、真实标签页跳转，失败明确反馈 |
| V1 | 两模块主流程、构建、存储与权限、性能、双语、README 更新 | CI 构建与实际 Mac 人工验收分开记录 |

不做独立 Todo 系统、专业绘图、云同步、插件市场或第三方工作流引擎。AI 作为远期可选 Action TODO；当前不接模型、不设计 AI 抽象层。语义搜索远期评估。先完成主流程，细节专项测试集中在最后，不用大量文档替代开发。

## 状态

规划已确定；代码实现及真实 macOS 验收尚未完成。
