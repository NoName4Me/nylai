# nylai

所需，信手拈来。一个本地优先、轻量常驻的原生 macOS 效率工具。

## 功能

- **截图**：冻结当前显示器，自动识别鼠标下的应用窗口或整屏，也支持自由框选；确认后可移动、八向缩放并继续编辑。
- **标注与外观**：矩形、椭圆、折线、箭头、自由画笔（降低颜色透明度即可当马克笔）、文字、步骤编号，以及可切换“马赛克／高斯模糊”和“方框／涂抹”的打码工具，并支持圆角、阴影、复制、保存和置顶。
- **文字提取与钉图缩放**：截图、长截图及最近截图可本地识别中英文，左图右文预览，按行双向选择高亮，支持复制选中或全部；钉图支持滚轮等比缩放，比例与透明度同排显示。
- **最近截图与拼图**：保留最近 50 张完成输出的截图；支持复制、保存、置顶、删除和自由拼图。
- **滚动截图**：在普通截图选区确认后点击工具栏按钮或按 `⌃⌘R` 开始；选区固定，旁边按完整长图等比预览结果，向上或向下滚动均可拼接；Enter 完成，Esc 取消，完成后在选区尺寸的无边框长图编辑窗口中继续标注、缩放和输出。
- **快捷键**：内置动作和应用动作均可录入、清除、启停；应用可启动、切换或在重复触发时隐藏。默认开启。
- **应用开窗**：应用快捷键与窗口切换共用激活逻辑；目标已运行但没有窗口或窗口全部最小化时，按点击程序坞图标的行为开窗或恢复。
- **鼠标手势**：按住右键绘制方向路径，支持全局或指定应用规则、nylai 动作、应用动作和单次组合键。默认关闭。
- **剪贴板**：记录文本和图片，支持带颜色的分类 tab、搜索、图文多选、批量删除与分组、图文富文本合并复制、纯文字合并、复制／粘贴、来源屏蔽及历史清理。悬浮预览延迟出现，可停留阅读并选取文本。分组内容独立保留；面板默认点外部关闭，也可钉住连续操作。旧置顶和短语迁入分组。默认关闭。
- **窗口切换**：`⌘Tab` 在应用间切换，保持 `⌘` 时用反引号键或左右键选择应用内窗口。应用图标可固定到前排，右键调整固定顺序；固定应用未运行时确认即可启动。8 个以内的窗口预览自适应完整展示，更多窗口可滚动，也可点击应用或窗口完成切换。默认关闭。
- **无限画布（开发分支）**：多画布、Markdown 便签及 Todo、图文粘贴、自由绘图、缩放平移、编组和撤销，支持置顶便签、折叠便签、OCR 搜索及 PNG 导出。截图和剪贴板可主动发送内容到画布。默认关闭。
- **Launcher（开发分支）**：固定 `⌘␣`，聚合应用、命令、文件、窗口、剪贴板、画布、截图与可选浏览器数据，支持专项搜索、拼音、别名、收藏、Quicklinks、计算及结果操作。默认关闭。
- **模块开关**：设置中的「功能」页统一启停截图、访达增强、快捷键、鼠标手势、剪贴板、窗口切换和系统监控；关闭会释放运行资源，但保留配置和历史。
- **系统监控**：默认关闭，开启后可在设置侧栏配置 CPU、内存、网络和存储，以及哪些读数直接显示在菜单栏。点击图标打开无箭头浮层，点击外部关闭；可快速打开活动监视器、网络设置、系统存储和磁盘工具。菜单栏读数持续更新，其余项目仅在浮层打开时采样。
- **访达增强**：通过原生 Finder Sync 扩展提供“新建文本文件”“复制路径”“在此打开终端”，并检测已安装的 Microsoft Office／WPS，增加带图标的 Word／Excel／PowerPoint 或 WPS 文字／表格／演示二级菜单。可在设置的“功能”页随时关闭模块，右键菜单会立即隐藏；系统扩展本身仍在“启用扩展／管理扩展”中由系统管理。文本文件直接创建“未命名.txt”并进入原位重命名；Office／WPS 文件优先复制应用空白模板，缺少模板时使用内置最小 OOXML 包。真实 Finder 的多选与云盘兼容仍待验收。

首次安装时截图、访达增强和快捷键默认开启，其余功能模块默认关闭。截图默认使用 `⌥A`，Launcher 启用后通过事件拦截接管固定 `⌘␣`（需要辅助功能及输入监控权限；无需修改 Spotlight 的系统设置），其他动作初始不分配快捷键。

通用设置支持“跟随系统”“英文”“简体中文”。切换后界面、菜单栏菜单和独立窗口即时更新，不需要重新启动；应用名在简体中文下显示为「拈来」，英文下显示为「Nylai」。

## 无限画布与 Launcher（开发分支）

在设置的「功能」中分别开启。画布可通过菜单栏或自定义快捷键打开，双击空白处创建便签，粘贴图文，空格拖动平移，Command 滚轮或触控板缩放。Markdown 目前采用编辑窗口与预览切换，并非行内富文本编辑器。点击标题栏中的画布名切换、新建或管理画布；便签左上角色点换色，右上角折叠或展开。图形工具在二级栏选择。点击缩放百分比回到 100% 并按内容居中，键盘按钮查看快捷键。画布仍可配置全局快捷键；快速记录功能已移除。画布数据存放在 `~/Library/Application Support/nylai/Boards`；图片独立于历史记录，删除后保留资源以支持撤销，暂未提供垃圾回收。

Launcher 支持 `app:`、`file:`、`win:`、`clip:`、`board:`、`img:`、`tab:` 等搜索前缀。设置中的搜索目录仅按需有界扫描；系统文件使用 Spotlight，不另建全盘索引。Quicklinks 支持 `{query}` 参数。浏览器来源默认关闭，开启标签页搜索可能触发自动化授权，书签或历史读取可能受完全磁盘访问权限及浏览器版本限制。浏览器私密标签页的排除能力尚未验证，敏感场景建议保持此来源关闭。配置保存在 `~/Library/Application Support/nylai/Launcher`。

当前为开发分支实现，尚未通过真实 macOS 构建与交互验收，详见 [实施计划](docs/BOARD_LAUNCHER_PLAN.md)。

## 环境

- 最低运行系统：macOS 14.0。
- 发布工程使用 Xcode 26 或更高版本，Swift 6 语言模式，无第三方依赖。
- 本机已验证：macOS 26.7.2、Apple Silicon、Xcode 27.2、Swift 6.4.2、macOS 27.2 SDK。
- macOS 14 实机、Intel Mac、多显示器 Retina 和不同鼠标设备尚未验证。

## 构建与运行

首次开发前运行 `sh scripts/install-git-hooks.sh`，启用提交信息校验。提交使用 `feat: 描述`、`fix: 描述` 等 Conventional Commits 格式，可带 scope；CI 同步校验新增提交。

1. 用 Xcode 打开 `nylai.xcodeproj`。
2. 选择 `nylai` scheme 和 `My Mac`，按 `⌘R`。
3. 点击菜单栏图标直接打开设置；右键图标可退出应用。

命令行：

```sh
xcodebuild -project nylai.xcodeproj -scheme nylai -configuration Debug \
  -destination 'platform=macOS,arch=arm64' test \
  CODE_SIGN_IDENTITY='-' CODE_SIGNING_REQUIRED=NO

xcodebuild -project nylai.xcodeproj -scheme nylai -configuration Release \
  -destination 'platform=macOS,arch=arm64' build \
  CODE_SIGN_IDENTITY='-' CODE_SIGNING_REQUIRED=NO
```

工程默认使用本地 ad-hoc 签名，不需要开发者会员。固定 bundle ID 为 `com.noname4me.nylai`；Debug 和 Release 都使用稳定 designated requirement，避免每次重建后系统把 nylai 当成新应用而丢失屏幕录制授权。移动应用或系统隐私状态变化仍可能要求重新授权。

DMG 由 GitHub Actions 构建为 arm64 与 Intel 通用的 ad-hoc 签名版本，并可直接上传到 GitHub Release。推送 `v0.1.0` 形式的标签会自动发布；也可以在 Actions 中手动运行 `Release macOS app`，只下载工作流产物或同时创建 Release。该流程不需要 Apple Developer 账号或仓库 secrets。

ad-hoc 签名未经过 Apple 公证，首次打开时 Gatekeeper 会显示开发者无法验证的警告，需要右键应用并选择“打开”。

## 权限

- **屏幕录制**：截图、窗口识别、滚动捕获和窗口切换预览需要；在实际使用时请求。
- **辅助功能**：鼠标手势、窗口切换和快捷键录入需要；快捷键录入只在开始录制时请求。每次应用启动最多触发一次系统授权提示，拒绝后可从设置页打开系统设置，不会反复堆叠弹窗。
- **输入监控**：窗口切换需要用它接管系统切换键。
- **事件发送**：手势“发送组合键”和剪贴板“直接粘贴”需要系统允许发送输入事件。仅在用户执行对应动作时检查或请求。
- 普通截图、全局快捷键和剪贴板读取不额外申请无关权限。

首次启用窗口切换时按“辅助功能 → 输入监控 → 屏幕录制”的顺序逐项请求权限，避免多个系统授权框互相覆盖。屏幕录制授权后通常需要重新启动应用。

如果在系统设置中删除过 nylai 的屏幕录制授权，再次截图时可按提示打开系统设置，点击列表下方的「+」并选择应用路径重新添加。授权后若当前进程仍提示需要权限，nylai 会提供「重新启动 nylai」入口，让新授权立即生效。

## 截图

触发后冻结鼠标所在显示器。移动鼠标会高亮应用窗口或整屏目标，并显示细的强调色全屏十字线和紧凑放大镜；十字线使用独立合成层跟随指针，放大镜按正方形区域采样，跟随应用明暗外观，显示像素坐标、HEX 与 RGB。单击确认，拖动则创建自由选区。确认后仍可移动选区、拖动八个居中于边线的手柄调整尺寸，像素尺寸显示在选区左上角。

底部工具栏提供标注工具和阴影；选中矩形、椭圆、折线、箭头、画笔、文字、步骤或打码后，下方出现对应颜色、粗细、线型、字号、块大小或边角样式，并用一条横向分隔线与顶层工具行区分。实线／虚线使用同一组水平线图标 tab。画笔可直接调整颜色透明度，低透明度笔触即马克笔。打码是一个顶层工具，内部用图标切换“马赛克／高斯模糊”和“方框／涂抹”：方框和涂抹都可调整打码强度，方框可重新选中调整，涂抹不可再次选中编辑，切换只影响下一次绘制、不转换已有对象。马赛克使用真实像素块；高斯模糊使用带边缘延展的高斯处理，保留颜色层次，并裁剪到方框或完整笔触范围。折线用左键点击确定起点和后续顶点，点击后立即自动连线；按住拖动可预览首段，右键结束本轮绘制。矩形、折线和画笔提供“圆角／直角”样式，默认按比例圆角且不提供半径参数；直角模式仍保留。箭头只保留等宽／渐宽、直线／弯曲和等宽箭头的实线／虚线，粗细方式使用对应箭头图标；渐宽箭头头部带有向内收的缺口和轻微圆角肩部，不再是普通三角形；弯曲时箭头按终点切线定向。右侧工具栏使用统一图标，提供选区、选择标注、撤销／重做／删除、滚动截图、重新选择、复制、保存、置顶和取消，图标在悬浮时显示同一套延迟功能提示。全屏或贴边选区时两组工具收进选区内部，普通区域和功能控件使用箭头光标。颜色通过紧凑弹层选择：左侧常用色阶，右侧饱和度／亮度、色相、透明度和 HEX，不调用系统取色器。

选区右下角内的圆点可拖动调整圆角；步骤标记通过四个角点等比缩放，矩形、椭圆、画笔和方框打码等对象可八向自由调整，缩放不改变描边粗细，并按类型保留最小尺寸，避免缩成不可见对象。选区与标注四边使用水平双向缩放光标，四角使用 45° 斜向双向缩放光标。折线、箭头、画笔、马赛克涂抹与高斯模糊涂抹支持方向约束：Shift 锁定水平／垂直，Control 锁定另一轴，Control+Shift 锁定 45°。绘制工具激活时可用鼠标滚轮调整粗细（方框或涂抹打码调整块大小或高斯模糊强度，范围 1–60），触控板精细滚动需累积到阈值，惯性滚动不再继续改值，连续滚动只重绘当前对象范围，停止后再合并持久化，避免整层刷新卡顿；绘制光标使用当前颜色绘制十字和实色圆形标示实际粗细。方框打码只显示十字星，不叠加圆形光标。回车复制，`Command + S` 通过系统保存面板选择位置，Esc 取消当前操作或退出截图。复制、保存和置顶会生成合成 PNG；取消、失败和未完成编辑不记录最近截图。
- 成功复制、保存或置顶后先恢复触发前的应用，再关闭截图覆盖层，避免临时前台状态带出设置页。

「最近截图」保留最近 50 张；关闭记录不会删除已有图片。「自由拼图」可从最近截图或本地 PNG、JPEG、HEIC 导入，自由摆放、缩放、调整层级和横竖排列。

滚动截图从普通截图进入：识别窗口或手动框选后，点击右侧“滚动截图”或按 `⌃⌘R`。采集保持目标应用前台，选区固定；最新拼接预览优先选区左侧居中，空间不足时自适应。编辑、复制、保存和取消为右下方优先的横排图标；Enter 编辑、Esc 取消。重复帧和短暂不稳定不中断采集，支持双向拼接。达到 100 帧或 4000 万像素时停止。无边框长图编辑窗口支持标注、外观、缩放及输出，工具栏优先放在视口外下方和右侧。

## 鼠标手势

在设置中添加规则，按住右键绘制 1～4 段方向路径，松开后执行。普通短右键仍会恢复原生菜单；有效手势不弹菜单，无效或取消路径不执行动作。

规则优先级：应用禁用名单 > 应用专属规则 > 全局规则。每个规则可绑定 nylai 功能、启动／切换应用或发送一次组合键。截图编辑、长图编辑和截图区域选择期间不会识别或拦截鼠标手势。

## 剪贴板历史

开启后按 500ms 有界观察系统剪贴板，只记录后续变化，不回填开启前内容。文本上限 1 MiB；图片编码上限 20 MiB、像素上限 4000 万。相同内容更新来源和时间，不新建重复记录。

浮动面板通过带颜色的 tab 分组、搜索文本与来源；支持方向键选择、图文勾选、批量删除与分组、复制和粘贴。多选时隐藏每行粘贴与操作菜单；纯文字按可见顺序合并为一个文本项，图文混选按可见顺序合成为一个 RTFD/HTML 富文本项目，图片嵌入文字之间，文字保持可编辑。接收方不支持富文本时自动使用纯文本回退，图片显示为 `[图片]`。悬浮预览延迟出现，鼠标进入预览不会关闭，长文本可滚动选取。默认复制、Esc、点击外部后关闭，钉住面板可持续操作。粘贴前核对目标进程、前台身份与剪贴板版本；目标失效或剪贴板被竞争改写时停止并给出反馈，不向其他应用误发。

macOS 不保证每次剪贴板写入都有可信来源；来源标记和前台应用只用于尽力过滤，不能作为安全凭证。Concealed、Transient、AutoGenerated 标记内容默认忽略。

## 窗口切换

开启后，`⌘Tab` 打开应用列表并默认选中上一个应用；继续按 Tab 循环，松开 `⌘` 后激活所选窗口。保持 `⌘` 时按反引号键或左右键切换所选应用的窗口；直接按 `⌘` 加反引号键进入当前应用的窗口切换。Shift 反向循环，Esc 取消。

固定应用按保存顺序排列在前，其余应用与窗口按最近使用顺序排列。面板打开后顺序保持稳定，主动固定、取消固定或调整固定顺序即时生效。应用图标上的固定按钮和右键菜单可管理固定项；未运行的固定应用仍保留，选择后启动。最小化窗口仍会列出，选择后会恢复并激活；已经关闭的窗口不会显示。缩略图按所选应用加载并缓存在内存，不写入磁盘。已运行但无窗口的应用仍可作为应用项打开。

## 本地数据

- 通用偏好：应用 `UserDefaults`。
- 快捷键：`~/Library/Application Support/nylai/shortcut-bindings.json`。
- 鼠标手势：`~/Library/Application Support/nylai/mouse-gestures.json`。
- 剪贴板：`~/Library/Application Support/nylai/clipboard-settings.json` 和 `clipboard/`。
- 最近截图：`~/Library/Application Support/nylai/ScreenshotHistory/`。

配置和索引使用版本化 JSON；历史文件保留损坏线索，不静默清空。关闭模块或删除历史不会修改系统剪贴板当前内容，也不会删除用户保存到其他位置的文件。

- 截图工具栏的 Liquid Glass 视觉、悬浮高亮与延迟提示，以及放大镜和全屏参考线的实际跟手表现。
- 使用 `Control + ↑` 等已有系统效果的组合键完成快捷键录入，确认原效果被拦截且新绑定生效。
- 鼠标手势在至少两个普通 GUI 应用中的真实事件 tap、普通右键菜单、Esc、tap 恢复和组合键发送。
- macOS 15.4+ 剪贴板访问行为、后台写入来源差异、敏感标记和未知来源表现。
- 剪贴板直接粘贴在多个应用、权限不足、目标退出和剪贴板竞争场景中的真实行为。
- 窗口切换的 `⌘Tab` 独占接管、遮挡窗口预览、指定窗口激活、权限拒绝／撤销和系统切换器恢复。
- macOS 14、多显示器 Retina、不同鼠标与键盘布局。
