# nylai

所需，信手拈来。一个本地优先、轻量常驻的原生 macOS 效率工具。

## 功能

- **截图**：冻结当前显示器，自动识别鼠标下的应用窗口或整屏，也支持自由框选；确认后可移动、八向缩放并继续编辑。
- **标注与外观**：矩形、椭圆、直线、箭头、自由画笔、文字、步骤编号、马赛克，以及圆角、阴影、复制、保存和置顶。
- **最近截图与拼图**：保留最近 50 张完成输出的截图；支持复制、保存、置顶、删除和自由拼图。
- **滚动截图**：在普通截图选区确认后点击工具栏按钮或按 `⌃⌘R` 开始；选区固定，旁边按完整长图等比预览结果，向上或向下滚动均可拼接；Enter 完成，Esc 取消，完成后在选区尺寸的无边框长图编辑窗口中继续标注、缩放和输出。
- **快捷键**：内置动作和应用动作均可录入、清除、启停；应用可启动、切换或在重复触发时隐藏。默认开启。
- **鼠标手势**：按住右键绘制方向路径，支持全局或指定应用规则、nylai 动作、应用动作和单次组合键。默认关闭。
- **剪贴板历史**：记录文本和图片，支持搜索、复制、置顶、删除、来源屏蔽、数量与按天清理，以及可选直接粘贴。默认关闭。
- **窗口切换**：`⌘Tab` 在应用间切换，保持 `⌘` 时用反引号键或左右键选择应用内窗口；触发后全屏显示系统玻璃或模糊背景、大应用图标和自适应窗口预览，也可直接点击应用或窗口完成切换。默认关闭。
- **模块开关**：设置中的「功能」页统一启停截图、快捷键、鼠标手势、剪贴板和窗口切换；关闭会释放运行资源，但保留配置和历史。

首次安装时快捷键默认开启，其余功能模块默认关闭。打开设置不分配快捷键；启用截图模块后，截图默认使用 `⌥A`。其他动作初始不分配快捷键。

应用名称跟随系统语言显示：简体中文为「拈来」，其他语言为「Nylai」。

## 环境

- 最低运行系统：macOS 14.0。
- 工程要求：Xcode 16 或更高，Swift 6 语言模式，无第三方依赖。
- 本机已验证：macOS 26.7.2、Apple Silicon、Xcode 27.2、Swift 6.4.2、macOS 27.2 SDK。
- macOS 14 实机、Intel Mac、多显示器 Retina 和不同鼠标设备尚未验证。

## 构建与运行

1. 用 Xcode 打开 `nylai.xcodeproj`。
2. 选择 `nylai` scheme 和 `My Mac`，按 `⌘R`。
3. 点击菜单栏图标，从菜单中选择“设置…”打开设置。

命令行：

```sh
xcodebuild -project nylai.xcodeproj -scheme nylai -configuration Debug \
  -destination 'platform=macOS,arch=arm64' test \
  CODE_SIGN_IDENTITY='-' CODE_SIGNING_REQUIRED=NO

xcodebuild -project nylai.xcodeproj -scheme nylai -configuration Release \
  -destination 'platform=macOS,arch=arm64' build \
  CODE_SIGN_IDENTITY='-' CODE_SIGNING_REQUIRED=NO
```

工程默认使用本地 ad-hoc 签名，不需要开发者会员。固定 bundle ID 为 `com.noname4me.nylai`；Debug 和 Release 都使用稳定 designated requirement，避免每次重建后系统把 nylai 当成新应用而丢失屏幕录制授权。移动应用或系统隐私状态变化仍可能要求重新授权。

DMG 由 GitHub Actions 构建为 arm64 与 Intel 通用的 ad-hoc 签名版本，并可直接上传到 GitHub Release。推送 `v0.1.0` 形式的标签会自动发布；也可以在 Actions 中手动运行 `Release macOS app`，只下载工作流产物或同时创建 Release。该流程不需要 Apple Developer 账号或仓库 secrets。

ad-hoc 签名未经过 Apple 公证，首次打开时 Gatekeeper 会显示开发者无法验证的警告，需要右键应用并选择“打开”。

## 权限

- **屏幕录制**：截图、窗口识别、滚动捕获和窗口切换预览需要；在实际使用时请求。
- **辅助功能**：鼠标手势、窗口切换和快捷键录入需要；快捷键录入只在开始录制时请求。每次应用启动最多触发一次系统授权提示，拒绝后可从设置页打开系统设置，不会反复堆叠弹窗。
- **输入监控**：窗口切换需要用它接管系统切换键。
- **事件发送**：手势“发送组合键”和剪贴板“直接粘贴”需要系统允许发送输入事件。仅在用户执行对应动作时检查或请求。
- 普通截图、全局快捷键和剪贴板读取不额外申请无关权限。

首次启用窗口切换时按“辅助功能 → 输入监控 → 屏幕录制”的顺序逐项请求权限，避免多个系统授权框互相覆盖。屏幕录制授权后通常需要重新启动应用。

如果在系统设置中删除过 nylai 的屏幕录制授权，再次截图时可按提示打开系统设置，点击列表下方的「+」并选择应用路径重新添加。授权后若当前进程仍提示需要权限，nylai 会提供「重新启动 nylai」入口，让新授权立即生效。

## 截图

触发后冻结鼠标所在显示器。移动鼠标会高亮应用窗口或整屏目标，并显示细的强调色全屏十字线和紧凑放大镜；十字线使用独立合成层跟随指针，放大镜按正方形区域采样，跟随应用明暗外观，显示像素坐标、HEX 与 RGB。单击确认，拖动则创建自由选区。确认后仍可移动选区、拖动八个居中于边线的手柄调整尺寸，像素尺寸显示在选区左上角。

底部工具栏提供标注工具和阴影；选中矩形、椭圆、直线、箭头、文字、步骤或马赛克后，下方出现对应颜色、粗细、线型、字号或块大小。右侧工具栏使用统一图标，提供选区、选择标注、撤销／重做／删除、滚动截图、重新选择、复制、保存、置顶和取消，图标在悬浮时显示底色并延迟显示功能提示。全屏或贴边选区时两组工具收进选区内部，普通区域和功能控件使用箭头光标。颜色通过紧凑弹层选择：左侧常用色阶，右侧饱和度／亮度、色相和 HEX，不调用系统取色器。

选区右下角内的圆点可拖动调整圆角；步骤标记通过四个角点等比缩放，矩形、椭圆、画笔和打码等对象可八向自由调整，缩放不改变描边粗细。回车复制，`Command + S` 通过系统保存面板选择位置，Esc 取消当前操作或退出截图。复制、保存和置顶会生成合成 PNG；取消、失败和未完成编辑不记录最近截图。

「最近截图」保留最近 50 张；关闭记录不会删除已有图片。「自由拼图」可从最近截图或本地 PNG、JPEG、HEIC 导入，自由摆放、缩放、调整层级和横竖排列。

滚动截图从普通截图进入：识别窗口或手动框选后，点击右侧“滚动截图”或按 `⌃⌘R`。开始后选区保持固定，附近按完整长图等比显示最新拼接内容；预览优先放在选区外，空间不足时先压缩到侧边，仍无法容纳才悬浮在选区内部。选区仅保留滚动提示和左上角“完成”，Enter 完成、Esc 取消。重复帧和短暂不稳定不会中断采集，向上或向下滚动都能拼接。达到 100 个有效拼接帧或 4000 万像素时停止，并在原选区位置打开无边框长图编辑窗口；此时不能再次调整选区或启动滚动截图，但可继续标注、调整外观、缩放查看、复制、保存和置顶。

## 鼠标手势

在设置中添加规则，按住右键绘制 1～4 段方向路径，松开后执行。普通短右键仍会恢复原生菜单；有效手势不弹菜单，无效或取消路径不执行动作。

规则优先级：应用禁用名单 > 应用专属规则 > 全局规则。每个规则可绑定 nylai 功能、启动／切换应用或发送一次组合键。截图编辑、长图编辑和截图区域选择期间不会识别或拦截鼠标手势。

## 剪贴板历史

开启后按 500ms 有界观察系统剪贴板，只记录后续变化，不回填开启前内容。文本上限 1 MiB；图片编码上限 20 MiB、像素上限 4000 万。相同内容更新来源和时间，不新建重复记录。

浮动面板支持搜索文本与来源、方向键选择、Enter 复制、Esc 关闭，以及置顶、删除和直接粘贴。直接粘贴会先保存原目标应用，在写入、激活和前台身份验证通过后发送一次 `Command + V`；目标退出、前台改变或剪贴板被竞争改写时停止，不向其他应用误发。

macOS 不保证每次剪贴板写入都有可信来源；来源标记和前台应用只用于尽力过滤，不能作为安全凭证。Concealed、Transient、AutoGenerated 标记内容默认忽略。

## 窗口切换

开启后，`⌘Tab` 打开应用列表并默认选中上一个应用；继续按 Tab 循环，松开 `⌘` 后激活所选窗口。保持 `⌘` 时按反引号键或左右键切换所选应用的窗口；直接按 `⌘` 加反引号键进入当前应用的窗口切换。Shift 反向循环，Esc 取消。

应用与窗口按当前窗口前后顺序分组；面板打开后顺序冻结。最小化窗口仍会列出，选择后会恢复并激活；已经关闭的窗口不会显示。缩略图按所选应用加载并缓存在内存，不写入磁盘。无窗口应用仍可作为应用项激活。

## 本地数据

- 通用偏好：应用 `UserDefaults`。
- 快捷键：`~/Library/Application Support/nylai/shortcut-bindings.json`。
- 鼠标手势：`~/Library/Application Support/nylai/mouse-gestures.json`。
- 剪贴板：`~/Library/Application Support/nylai/clipboard-settings.json` 和 `clipboard/`。
- 最近截图：`~/Library/Application Support/nylai/ScreenshotHistory/`。

配置和索引使用版本化 JSON；历史文件保留损坏线索，不静默清空。关闭模块或删除历史不会修改系统剪贴板当前内容，也不会删除用户保存到其他位置的文件。

## 工程结构

```text
nylai.xcodeproj/             Xcode 工程与共享 scheme
nylai/
  App/                       应用生命周期、菜单栏、模块编排
  Features/
    Clipboard/               剪贴板模型、监听、历史面板与直接粘贴
    Collage/                 自由拼图
    GlobalShortcuts/         绑定配置、注册协调与应用动作
    MouseGestures/           手势识别、事件 tap、规则与设置
    Screenshot/              截图、标注、输出、置顶、历史与滚动截图
    Settings/                SwiftUI 设置与快捷键录入
    WindowSwitching/         系统键会话、窗口目录、预览面板与激活
  Shared/
    Modules/                 模块意愿、运行状态与生命周期
    Permissions/             系统权限状态与设置入口
    Preferences/             本地偏好
    UI/                      截图编辑器统一图标与主题颜色
nylaiTests/                  自动测试
```
